## 既知の限界・決着済みの論点

- 項を本文ごと別の新しい文面に差し替えて ID を付け替える形のうち引いた先の頭を持たないもの・付け替え先の頭も言い換えたうえで元の項の頭の文面を付け替え先の本文に写す形・元の項の引用の行の前後の文面を新しい項に写して付け替える形は見ない（項の頭だけを守る。#1194・#1423 の決着。docstring に書いた）。
- 改名は `git diff -M` で見つかったものだけを追う（#1423 の決着）。
- 付け替え先の元の頭の文面がその項に残らない言い換え（縮める・別の文に書き換える）への付け替えは見ない（#1430 の決着）。
- 引用の受け継ぎは、元の項の行の頭の前か後ろの文面の全部が頭と続いて残るかで見る。前後の文面が短い（`）` だけなど）行では弱い——そうした本文の書き方は実物の `prompts/` に無い。
