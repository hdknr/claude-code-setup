## 0. いまの対処が、なぜ一般解でないか

`judge()` は **`rc=0` のとき、出力が 1 バイトも変わらなければ `当てられなかった` に倒す**
（#151 の「守る 13」）。**これは 0 で終わる SKIP を見分けているのではなく、
たまたま出力が一致するから効いている。**

| `red` の性質 | 変異の前後の出力 | いまの判定 | 正しいか |
| --- | --- | --- | --- |
| 判定して、変異を見逃した | 変わる | `緑のまま` | **正しい**（主張が偽か、検査が弱い） |
| **判定せずに 0 で終わる**（出力が決まっている） | 同じ | `当てられなかった` | **正しい**（#151 が塞いだ） |
| **判定せずに 0 で終わる**（出力に時刻・件数・乱数が混じる） | **変わる** | **`緑のまま`** | **誤り。これが #156** |
| 判定して、変異を見逃した（出力が実行ごとに変わる） | 変わる | `緑のまま` | 正しいが、**上と区別できていない** |

**3 行目と 4 行目が、観測の上で同じ形をしている。** これが塞がっていない穴である。

## 6. 既知の限界・決着済みの論点

**#156 は 3 つの方向を挙げていた。どれも採らない。** 理由を書く。

| 方向 | 決着 | 理由 |
| --- | --- | --- |
| **1. 退避先に使い捨ての `git` を用意する**（`git init` ＋ base ref を作る） | **採らない** | **穴を 1 つ埋めるだけで、題は残る。** base を要する検査は走るようになるが、**「0 で終わる SKIP」は base 以外の理由でも起きる**（道具が無い・環境変数が無い・対象が無い）。**しかも「本物の履歴ではない」ことに依存する検査が別の形で壊れうる**——**#157 の周で `.git` を退避先に持ち込まないことの重さを実測している** |
| **2. `red` に「判定していない」を申告させる**（専用の終了コード・機械可読な 1 行） | **採らない** | **リポジトリ側の検査すべてに規約を課す。** **規約は守られなければ効かず、守られたかを機械で見る手段がまた要る**——**この歯止め自身が「散文の規約は破られる」ことの記録である。** さらに **`red` は外部のコマンドでもよい**ので、規約を課せない `red` が必ず残る |
| **3. base を要する `red` を明示的に拒否する** | **採らない** | **当てられる範囲が狭まるのに、題は残る**（base 以外の理由の SKIP）。**「base を要するか」を機械で見る手段も無い** |
| **4（採る）. 出力で判別できるかを、その場で測る** | **採る** | **`red` の中身に規約を課さない。** **`緑のまま` に倒れる直前にだけ陽性対照をもう 1 度走らせ、出力が変われば「この `red` では判別できない」として `当てられなかった` に倒す。** **判定したかどうかは見ない**——**見るのは「出力が主張を判別できるか」だけ**で、**それはこの歯止めが実際に使っている観測そのものである** |

**採った方向の限界を、先に書いておく**（§3.3 と同じ）:

- **「判定したかどうか」は見ていない。** 見ているのは**出力が判別に使えるかどうか**だけ。
- **決定的であることは証明できない。** **2 回とも同じだった、としか言えない。**
- **低い確率で出力が変わる `red` は、いまでも `緑のまま` に落ちうる。**

| ほかの論点 | 決着 | 理由 |
| --- | --- | --- |
| **陽性対照を毎回 2 度走らせる** | **採らない** | **もともと重い歯止めがさらに倍になる**（P4）。**判別が要るのは `緑のまま` に倒れる直前だけ** |
| **`緑のまま` を廃止して全部 `当てられなかった` にする** | **採らない** | **歯止めが何も言わなくなる**（P2）。**本物の「主張が偽」を見つけるのがこの道具の目的である** |
| **`CLAUDE.md` に判定の説明を書く** | **採らない** | **`CLAUDE.md` は「docstring を正とする」と書いている。** **列挙を 2 箇所に置くのが、この規約が直した形そのもの。** **`#155` が同じファイルを触っていることも理由になる** |

**決着の*理由*が誤っていると判断したなら、それは新しい反証である。**
