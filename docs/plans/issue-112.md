### 周中の観測（この周自身がガードに当たった）

**この計画ファイルを書く `mkdir -p … && cat > … <<'EOF'` が拒否された**（2026-09-19）。
理由節は `is too complex to verify that it stays inside the worktree.`、
対処文は `Split it into plain, separate commands and run them from <PATH>`。
実際の書き込みは、**長いヒアドキュメントを送り直す文脈コストを避けて**
`SKILL.md` の既存の規定（ファイル編集がガードに当たるならファイル編集ツールで行う）に従った。

**そのうえで、対処文が正しかったかを 1 次元だけ振って確かめた**（2026-09-19・各形 1 回・この 1 環境）:

| 形 | 結果 |
| --- | --- |
| `cat > <リテラルなパス> <<'EOF'`（本文に `git` を複数回）+ `echo` | **通る**（陽性対照） |
| **同じ本文**に `mkdir -p docs/plans && ` を**前置しただけ** | **拒否**（理由節・対処文とも上と同一） |

**振った次元は複合の有無 1 つだけ**なので、**この対では**対処文（割る）が正しかったと言える。

**ただしこれを「複合が効いている」と読んではならない。**
#110 の実測では**複合単独（`git` あり・なし）は通っている**。
**この対が示すのは、複合とヒアドキュメントの組み合わせで拒否が出たこと**までで、
**どちらが効いたかは判別していない**。**境界の主張として書かない。**
