### 決めたこと

- **#551**: 上書きを断る行（`write_outputs` の `Stop`）が名指ししたパスは、続く「今回の出力ではない」の行で名指ししない。同じファイルかは
  `lstat` の (st_dev, st_ino) で見る（大文字小文字だけ違う綴りで出会っても、symlink を辿らずに同じと分かる）。印が読めない場所でも同じ。
- **#553**: 0 で終わるとき、書いたあとの出力の場所で `leftover_lines` を当て、残った出力の名前のファイル（印に無いもの）を標準エラーに名指しする。終了コードは 0 のまま（#554 の決定 2）。
  書いたばかりの印は今回の出力を名指しするので、今回の出力は名指しされない。
- **#550**: 試料の名前で殺し手を名指しするなら、その名前の試料**だけ**を走らせて殺せることを、変異の確かめ自体が見る形にする——
  `leftover_problems` の `only` で、いつも走っていた「消せない場所」「印がディレクトリ」「辿れない場所」も名前で選ぶ（`only` を渡せば他は走らない）。名札はそれに合わせる。
- **#552**: N1 は `spec-figure-01.svg.bak`（前方一致で通る名前）を出力の名前でないものに足す。N2 は `--out <場所>/plan.md` の経路と `plan.md`・`plan.pptx` を足す
  （ほかの経路では出力の名前でない）。N3 は辿れない symlink の印の試料を足す（「印を読めない」と名指しする）。
- **#508**: 図の入った試料（v1 に図 1 つ、v2 で図を 1 つ足す）で、(a) 印があれば図が増えても 0 で両方を書く、(b) 印に無い `spec-figure-02.svg` が在ると、
  図が増えない実行は 0 で名指し（#553）、図が増える実行は「上書きしない」の 2 でそのファイルを 1 度だけ名指しし、消さない、を確かめる。
  **#441 が書いた「図が増えた」の文言は #498 で「その名前を `--out` に渡した」に書き換わり、いまは文面に無い**——今の文面（「上書きしない」で 2 になったら印の無いファイルがある）と
  食い違わないことを試料で見る。食い違えば文言を直す。
- 仕様の穴は無い——5 件とも Issue（と #554 の決定）が方向を決めている。
