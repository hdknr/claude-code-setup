## 設計

CommonMark（cmark-gfm）は `****` を 1 つの区切りの並び（delimiter run）として読む。閉じの `**` と開きの `**` を隣り合わせた形は、
並びの両側が文字なら 3 の倍数の規則（2 + 4 = 6）で組めず、片側が句読点なら片方の向きにしか働かず、どちらでも `*` が字のまま残る。
著者の意図どおりに組む今の判定は 2・3 の並びしか数えないので、4 つ以上の並びは素通りした（#996 の C-R4・D-R1）。

4 つ以上の並びは意図の推測では決まらない（`****二重****` は入れ子の太字として正しく描かれ、`**一つ*****二つ***` も描かれる）ので、
**段落ごとに `*` の並び（1 つを含む）を CommonMark の「process emphasis」の手順でなぞり**、
**4 つ以上の並びのうち、組みきれずに字のまま残る `*` があるものだけを落とす**。2・3 の並びの判定はいまのまま。

各試料の描かれ方は、GitHub の描画（`gh api -X POST /markdown`、`mode=gfm`）と pandoc（`-f commonmark`）で確かめる。
