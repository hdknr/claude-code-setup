## 既知の限界・決着済みの論点・関門の指摘の採否

- V3・V4 は直さない（Issue が任意とした。`触らない:`）。指摘されたら残課題。
- `<<<`（ヒアストリング）・1 行に 2 つの `<<`・`$( )` の外の `( )` の中の読み方は変えない。
- 引用符の辿り方は既存の `QUOTED`（単一引用符は次の `'` まで・二重引用符は `\` の跳ばしつき・閉じない引用符は文字のまま）に合わせる。
  **（1 パス目まで）引用符の外の `\'` は跳ばさない**——`QUOTED` も跳ばさず（`echo don\'t && git commit …` の commit は、直す前から骨組みで隠れる）、片方だけ跳ばしても判定は変わらなかった
  （最初は跳ばす分岐を足したが、その変異が素通りして、効いていないと分かったので外した）。直す前からある読み方で、この周では変えない。
- 閉じない二重引用符の後ろの `<<` は、引用符の中と読む（`QUOTED` は文字のままと読む）。**2 パス目の D2 で、引用符の外の `\"` がこの形になって後退していたと分かった**——引用符の外の `\` の次の文字を跳ばすように直した。ほかに閉じない二重引用符になるのはシェルで走らないコマンドだけ。
