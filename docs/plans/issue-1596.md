## 方針

- 道具は screen-spec に置く（spec-loop は screen-spec に依存しない決まり。screen-spec は spec-loop を読み込んでよい）。表の置き場所・列・spec-loop の見つけ方と版の範囲・重ね方は
  `check-screens.py` を読み込み（写さない）、中間表現のパスは spec-loop の `merge-versions.py` の `SPEC_PATH`。重ねた全体（`merge` の書く中身）から画面・項目の表と `spec_ir.json` を読む。
- 画面 → 入口: `--map` の画面の行があればそれ、無ければ画面の `機能` の列（`tab`・`dialog` で空なら親の画面の `機能`）の機能のうち、中間表現に在り入力を持つ入口が 1 つだけなら決まる。
  0 なら理由（機能が空・中間表現に無い・入力を持つ入口が無い）、2 つ以上なら「1 つに決まらない」。
- 項目 → フィールド: 種類が `入力` の項目。`--map` の項目の行（パスか `保存しない`）があればそれ、無ければ項目名がフィールドのパスか末尾の名前に一致するもの（1 つだけなら引ける）。
- 順向き: 引けたパスが入口の入力の項目（入れ子は `a.b`・`rows[].x`）に無ければ食い違い。逆向き: 照らした入口（入力の項目を持つ画面から決まった入口）の入力の葉のうち、どの項目からも指されず、
  `--map` でシステムが埋めると宣言されてもいないもの。パスの変数は別に数える。
- 出力は既定で件数と種類だけ（画面は表の行の順の番号と種別。名前・ID・パスを出さない）。`--detail` で画面ID・項目の番号・入口の id・パスを出す（公開の場に貼らない注意つき）。
- 終了コードは食い違いの有無に依らず 0（関門ではない）。照らすもの（画面の表・中間表現）が無ければ 3、引数・読めない・対応の CSV の誤り・重ね合わせの違反は 2、spec-loop が見つからない・範囲の外は 4。
