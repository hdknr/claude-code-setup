## 方式（手順 2 の実測から決めた）

手順 2 で、全 77 本の回帰テストを audit hook のトレース付きで回した（scratchpad の試作。77/77 が通り、作業ツリーは変わらなかった）。分かったこと:

- **`-I` の子に渡るリポジトリのパスは、プラグインのスクリプトだけ**（9 本のテスト）——`-I` の子には hook が入らないので、その子が読む隣のファイルは見えない
- **環境を組み直して子を起こすテストが 5 本**——その子にも hook が入らない
- **実リポジトリを対象にした git は少数**（多くは `-C <一時ディレクトリ>`）——`intake-code` の `-C <repo>`、`rev-parse --path-format=absolute` など
- **import の仕組み（`FileFinder`）が `sys.path` のディレクトリを列挙する**——これを依存に数えると `scripts/` にファイルを足すたびに全件が回る
- **`shutil.rmtree` は `dir_fd` 基準の相対パスで `os.open` を呼ぶ**——cwd で解決するとリポジトリ直下の存在しないファイルに見える
- 見積り（直近 40 件の PR が変えたファイルと、各テストが読んだファイルを突き合わせる。import の列挙を除き、git の依存を保守的に数えた）:
  回し直す重み（所要時間の合計に対する割合）は**中央値 27%・p75 50%・最大 70%**。周の中のコミットごとの差分はもっと小さい

決めた形:

1. **依存の単位**: ファイルの中身（無いことも記録する）・ディレクトリの名前の一覧（`os.listdir`/`os.scandir`。import の仕組みからの列挙は除く）・git の状態（HEAD と `git status --porcelain`）
2. **hook が見ない子の扱い（粗くする）**: `-I`/`-E`/`-s` で起こした Python・環境を組み直した子・Python でない子（bash・node・git など）の引数に現れたリポジトリのパスは、
   そのパスが `plugins/<名前>/` の下ならそのプラグインのディレクトリ全体、`scripts/` の下なら `scripts/` の直下全体を依存にする
3. **git**: 実リポジトリを対象にした git は git の状態を依存にする。例外は `rev-parse` の配置だけを訊く形（中身に依らない）
4. **記録するのは緑だけ**。落ちた・中断した回は記録を消す。**回している間に依存が変わったら記録しない**（`check-all.py` の開始時刻より新しい mtime・git の状態の変化）
5. **キーに混ぜるもの**: Python の版と実行ファイル・OS・キャッシュの形式の版・`check-all.py` と hook の中身・テストの名前と引数（`--jobs` は除く）
6. **置き場所**: `git rev-parse --git-common-dir` の下の `check-all-cache/`（worktree の間で共有。中身で引くので共有して安全）。git のリポジトリでなければキャッシュを使わない
7. **出力**: `  CACHED <名前>` の行。集計は「回した」「キャッシュ」を分けて数える（`CACHED` を `OK` に数えない）。`--no-cache` で全部回す（記録は書く）

## 既知の限界・決着済みの論点

| 論点 | 決着 | 理由 |
| --- | --- | --- |
| 歯止めもキャッシュに載せるか | 載せない（常に回す） | 歯止めは実リポジトリの中身そのものを広く読む（指し先の実在・リンク・版）——依存がリポジトリ全体に近く、当たらない。重いのは `check-mutation-claims.py`（67 秒）だけで、並列の中で回る |
| 依存の粒度をプラグイン単位にするか、ファイル単位にするか | ファイル単位。hook が見ない子だけ粗くする | 見積りで、プラグイン単位は回し直す重みの中央値 70%、ファイル単位は 27%。粗くするのは取りこぼしうる経路に限る |
| `sitecustomize` で差し込むか | `usercustomize` | Homebrew の Python は自前の `sitecustomize` を持つ（実測）。隠すと挙動が変わる |
| 取りこぼしをどこで止めるか | PR 側の CI | CI は `check-all.py` を通さず全部回す。#831 で受け入れた「ローカルで省いた分を CI で捕まえる」と同じ形 |
| `.git/` の下のファイルと一覧 | 依存に入れない（git の中身への依存は git コマンドの側で捉える） | 試作のトレースでは、34 本の `.git` の読み取りは `rmtree` の `dir_fd` 相対の見かけで、一覧は `test-check-mutation-claims` が写すときの列挙だけだった。`.git/index` などを中身で比べると毎回外れる |
