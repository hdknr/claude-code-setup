**I2. 変異テスト**: 次の変異をブロックに 1 箇所ずつ入れると、少なくとも 1 ケースが赤になる。
変異ごとに、**壊す文字列がブロックにちょうど 1 回現れる**ことを先に確かめる（届いていない変異は緑になるので）。
境界に `-` を足す（Issue の実物）／境界から `/`・`#`・`?` をそれぞれ外す／境界の判定を外す（素の前方一致）／
完全一致の優先を外す（先頭から取る）／`or ''` を外す／`.get('url')` を `['url']` に／`hit[0]` を `hit[-1]` に／
`https://` の拒否を外す／（cmux）ブラウザの絞り込みを外す・1 枚ずつの取得を外す。

**I3. 抽出が壊れたら赤**: 見出しの下に `bash` ブロックが無い・1 行目が `TARGET_URL=` でない・python 部分が見つからない、
のいずれでもテストは赤になる（黙ってケース 0 件で緑にならない）。

（本物の `orca` / `cmux` を起こさない）。書き込みは一時ディレクトリだけ。

**I5. 登録**: `check-all.py` の `TESTS` と `plugins.yml` に載り、`python3 scripts/check-all.py` が全部緑。

**I1 × I2 の交点**: 変異は**両スキル**に当てる（片方だけ殺せても、もう片方の同じ変異が生き残れば赤）。
