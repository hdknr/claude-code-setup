## 既知の限界・決着済みの論点

- **引用（リストの項）の中で閉じないコメントのブロックの後ろの本文**: GitHub は描画した HTML に閉じない `<!--` が残るので、

  この検査は CommonMark の構造どおり引用の終わりでコメントを閉じ、後ろの段落を見る——**表示されない行の崩れを出しうる（誤検出の向き）**。
  決着: **この周では変えない**（判定を変えない周。周の途中の課題として親に渡す）。試料 `quote-comment-closed.md` は、
  段落の中のコメントで HTML のコメントを閉じ、後ろの `**` が**表示される**形にしてあるので、構造と表示のどちらで読んでも 4 行目が崩れる。
- 「区切りの行のあとで表を開かない」は main で既に殺せる（#562 の試料）。9 件の 1 つとして名前を付けて残す（素通りに戻ったら見える）。
