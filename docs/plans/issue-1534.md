## 既知の限界・決着済みの論点

- 元の頭が書き出しの 3 字のほかに 3 字以上の続きを持たない短い頭（`AAAB` など）は、引用を頭に上げる言い換えも 1 で止まる（止まる向き。本物の台帳に該当する頭は無い。V1）。
- 続きの 3 字は、書き出しの前に置いても通る（位置を見ない。CR2）。
- 元の頭の書き出しの後ろに、元の頭の続きの 3 字を 1 つでも持てば、付け替え先の旧い頭の写しを置く付け替えも 0 で通る（`AAA つめの行です: 「…」`。文字列では正当な言い換えと区別できない。docstring の「守らないもの」に名指し）。
- 逆に、元の頭の続きを全部言い換えて引用を頭に上げる言い換え（`AAA 1つ目（下の「…」と同じ）`）は 1 で止まる（止まる向き）。
