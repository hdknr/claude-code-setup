- 改名は `git diff -M` で見つかったものだけを追う（#1423 の決着）。
- 付け替え先の元の頭の文面がその項に残らない言い換え（縮める・別の文に書き換える）への付け替えは見ない（CR-p2-4・V-F1 の E2・E4。base から。項の頭だけを守る範囲の外）。
