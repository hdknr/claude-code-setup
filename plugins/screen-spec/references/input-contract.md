# 画面の入力と API の入力の照らし合わせ（調べる道具）

画面の入力の項目（`screen-items.csv` の種類が `入力` の行）と、その画面が呼ぶ入口（spec-loop の中間表現 `spec/spec_ir.json` の機能の `operation`）の入力が食い違っていないかを、
`scripts/survey-input-contract.py` が数える。この文書は道具の決まりの原本で、本体の定数はその写しである（写しがずれていないかは、このプラグインを置いているリポジトリ（hdknr/claude-code-setup）のテスト test-survey-input-contract.py が突き合わせる）。

**調べる道具であって、関門ではない**（#1596）。食い違いが何件あっても止めない。関門をどこに置くか（screen-spec の検査か spec-loop の scaffold か）と、
画面の項目と API のフィールドの対応を正本のどこに持たせるかは、この道具を案件の正本に当てた結果を見てから決める。だから**正本に新しい表は足さない**——
下の対応の CSV は、調べる人が正本の外に置く入力である。

```text
python3 scripts/survey-input-contract.py <docs ディレクトリ> [--upto <n>] [--map <対応の CSV>] [--detail] [--spec-loop <spec-loop のプラグインの根>]
```

v1〜v<n>（省略すると作業中の版まで）を spec-loop の重ね方で重ねた全体の `screens.csv`・`screen-items.csv`・`spec/spec_ir.json` を読む。ファイルは 1 つも書かない。
spec-loop の見つけ方と版の範囲は `check-screens.py` と同じ（`references/spec-loop.md`）。表の決まり（辿れること・根拠・未決定の印）は見ない——`check-screens.py` を先に回す。

## 照らし方

- **画面 → 入口**: 対応の CSV に画面の行があればそれ。無ければ画面の `機能` の列の機能（種別が `tab`・`dialog` で `機能` が空なら、親の画面の `機能`。親も空なら、さらに親）のうち、
  中間表現に在り、入力の項目を 1 つ以上持つ入口が 1 つだけなら決まる。
- **項目 → フィールド**: 対応の CSV に項目の行があればそれ（フィールドのパスか `保存しない`）。無ければ、項目名が入口の入力のパス全体か、パスの末尾の名前と同じ文字列のもの（1 つだけなら引ける）。
  言い換え・辞書での推定はしない——日本語の項目名と英語のフィールド名は引けず、「当たるフィールドが無い」に数える（それを数えるのが目的の 1 つ）。
- **フィールドのパス**: 入口の入力の項目名を、オブジェクトの中は `.`、配列の要素は `[]` でつなぐ（`code`・`meta.note`・`rows[].qty`・配列の配列の要素 `m[]`）。
  文字列の配列は配列の名前で書く（`tags`）。項目が親のパス（オブジェクト・配列）を指せば、その下の葉を全部指したとする。
- **順向き**: 引けたパスが入口の入力に無ければ食い違い。
- **逆向き**: 入力の項目を 1 つ以上持つ画面から決まった入口だけを照らし、入力の葉のうち、どの項目からも指されないものを数える。
  パスの変数（入口の `path` の `{…}`）と、対応の CSV でシステムが埋めると宣言した葉は別に数える。入力の無い画面から決まった入口（一覧の検索など）は照らさず、その数を出す。

## 対応の CSV（`--map`）

UTF-8（BOM はあってもよい）。見出し行は `対象,値`。1 行が 1 つの対応で、`対象` が何に当たるかで行の意味が決まる。

| `対象` | `値` |
| --- | --- |
| 画面の表の `画面ID` | その画面が保存・送信に使う入口の `id`（中間表現の `operation` の `id`）。`機能` の列より先に使う |
| 項目の表の `番号`（種類が `入力` の項目） | その入口の入力のフィールドのパスか `保存しない`（選択のチェックボックスなど、保存・送信しない入力） |
| 中間表現の入口の `id` | その入口の入力のうち、システムが埋めるフィールドのパス（版の番号・作った人など）。1 行に 1 つで、何行でも書ける |

次のどれかに当たれば、照らす前に全部を出して 2 で止める: 見出し行が違う・列が 2 つでない・空のセル・`対象` がどれにも無い・`対象` が 2 つの種類に当たる・
種類が `入力` でない項目・同じ画面か同じ項目の行が 2 つ・値がパスの形（英小文字で始まる名前を `.` と `[]` でつないだもの）でない・システムが埋めると宣言したパスが入口の入力に無い。
**画面の行の入口が中間表現に無いのは止めない**——下の「画面の入口が引けない理由」の `対応の CSV の入口が中間表現に無い` に数える。

## 出力

既定の出力は件数と種類だけ。画面は画面の表の行の順の番号と種別で示し、**画面名・項目名・機能の題・画面ID・項目の番号・入口の id・パスを出さない**
（案件の名前・業務の中身を公開の報告に持ち出さない）。`--detail` を付けると、画面ID・項目の番号・入口の id・パスを出す（項目名・画面名・機能の題は出さない。公開の場に貼らない）。

出力は、照らした数（画面・入力の項目・入口）、画面ごとの行（入力の数・入口の決まり方・項目の結果の件数）、集計の 3 行（画面の入口・入力の項目（順向き）・入口の入力（逆向き））。
形の崩れた機能・入口（`operation` が無い・`id` が文字列でない・入口の `id` が重なる）は飛ばし、その数を出す。

### 画面の入口の決まり方

| 名前 | 意味 |
| --- | --- |
| `対応の CSV` | 対応の CSV の画面の行で決まった |
| `機能の列` | 画面の `機能` の列で決まった |
| `親の画面の機能の列` | `tab`・`dialog` の `機能` が空で、親の画面の `機能` の列で決まった |

### 画面の入口が引けない理由

| 名前 | 意味 |
| --- | --- |
| `機能が空` | `機能` の列が空（`tab`・`dialog` は親を辿っても空・親が無い・親が循環する） |
| `機能が中間表現に無い` | `機能` の列の機能が、どれも中間表現に無い |
| `入力を持つ入口が無い` | 中間表現に在る機能の入口が、どれも入力の項目を持たない |
| `入口が 1 つに決まらない` | 入力を持つ入口が 2 つ以上ある（タブやダイアログがどの入口で保存するかが表から決まらない） |
| `対応の CSV の入口が中間表現に無い` | 対応の CSV の画面の行の入口が、中間表現に無い |

### 項目の結果

| 名前 | 意味 |
| --- | --- |
| `一致` | 引けたパスが入口の入力に在る |
| `食い違い` | 引けたパスが入口の入力に無い |
| `保存しない` | 対応の CSV で `保存しない` と書いた |
| `引けない` | 対応を引けない（理由は下） |

### 項目が引けない理由

| 名前 | 意味 |
| --- | --- |
| `画面の入口が決まらない` | 項目の画面の入口が決まらない（対応の CSV にパスがあっても照らさない） |
| `当たるフィールドが無い` | 対応の CSV に行が無く、項目名がどのパスとも、どのパスの末尾の名前とも同じでない |
| `当たるフィールドが 2 つ以上` | 項目名が 2 つ以上のパス（の末尾の名前）と同じ |
| `画面が表に無い` | 項目の `画面ID` が画面の表に無い |

### 逆向き

| 名前 | 意味 |
| --- | --- |
| `どの項目からも指されない` | 照らした入口の入力の葉のうち、どの項目からも指されず、システムが埋めるとも宣言されていない |
| `システムが埋めると宣言` | 対応の CSV でシステムが埋めると宣言した |
| `パスの変数` | 入口の `path` の `{…}` の項目 |

## 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 照らした（食い違い・引けない箇所が何件あっても 0——関門ではない） |
| 3 | 照らすものが無い——重ねた全体に画面の表か項目の表が無い・中間表現が無い |
| 2 | 判定していない——引数の誤り・`docs` が無い・`--upto` の版が無い・読めない・見出し行が決まりと違う・対応の CSV の誤り・重ね合わせが spec-loop の決まりに反する・想定外の例外 |
| 4 | 照らす前に止めた——spec-loop が見つからない・spec-loop の版が読めない・対応の範囲の外 |

## 照らさないもの

- 型・桁・必須の食い違い、画面の表示の項目と API の出力の対応、出力・振る舞いの食い違い（#1596 の決定が範囲の外にした）。
- Markdown で書いた画面設計書（読むのは画面の表だけ。表へ移してから当てる）。
